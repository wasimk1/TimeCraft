# ⏳ TimeCraft

**TimeCraft** is a modern and responsive Date & Time Calculator built using Angular.

It provides simple utilities for calculating differences between dates and times directly in the browser. The application is completely frontend-based and does not require any backend, API, or database.

## ✨ Features

### 📅 Date Calculator

- Select a Start Date and End Date
- Calculate the difference between two dates
- Display total number of days
- Display weeks and remaining days
- Simple input validation
- Reset calculation

### ⏰ Time Calculator

- Select a Start Time and End Time
- Calculate the duration between two times
- Display hours and minutes
- Display total minutes
- Supports overnight time calculations
- Reset calculation

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Angular CLI

Check your installed versions:

```bash
node -v
npm -v
ng version
```

### Clone the Repository

```bash
git clone https://github.com/wasimk1/TimeCraft.git
```

Navigate to the project directory:

```bash
cd TimeCraft
```

Install the required dependencies:

```bash
npm install
```

Start the Angular development server:

```bash
ng serve
```

Or automatically open the application in your browser:

```bash
ng serve -o
```

The application will normally be available at:

```text
http://localhost:4200
```

## 🔒 No Backend Required

TimeCraft runs entirely in the browser.

It does **not** require:

- ❌ ASP.NET Core
- ❌ Web API
- ❌ Database
- ❌ Authentication
- ❌ External API

All date and time calculations are performed locally using Angular and TypeScript.
